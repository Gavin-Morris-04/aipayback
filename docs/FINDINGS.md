## Caveats (read these before quoting any number)

- SEC filings only (10-K, 10-Q, earnings releases). Promises made only on earnings calls or in the press are not included.
- Promises from late 2025 have had little time to show results; many read "No evidence yet" for that reason alone.
- A status describes what later filings report. It is not a judgment of management, and none of this is investment advice.
- Groups with fewer than 5 items are marked "too few to compare"; small differences between sectors are not meaningful at these sample sizes.
- Accuracy of the underlying labels: see the evaluation table in the README and the Methodology page.
